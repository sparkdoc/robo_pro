## Component Specifications

### Microcontroller
- Arduino-compatible board
- Refer to included documentation for specific model

### Motor Driver
- Compatible with Adafruit Motor Shield library
- Supports DC motors

### Ultrasonic Sensor
- Used for distance measurement
- Object detection and avoidance

### Line Sensor
- Used for line detection
- Line following applications

## Learning Resources

The kit includes learning guides for:
1. Basic Robot Control
2. Object Avoidance
3. Line Following

## Power Specifications

- Power: 6x AA batteries
- Voltage: ~9V (6x 1.5V batteries)
- Always disconnect power when uploading code
